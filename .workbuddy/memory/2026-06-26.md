# 2026-06-26 工作日志

## 摘要空白问题修复
- 根因：网页抓取源（网易/新浪/搜狐）混入大量自媒体号、视频页、图集页，正文提取失败或提取到垃圾内容；AI 摘要失败后 `--articles-json` 模式没有规则清洗兜底，导致摘要为空。
- 修复：
  1. `_enrich_article_content()` 更积极地抓取原文：字数<80 或段落<2 时触发 fetch。
  2. 新增中新网 `left_zw` / `<!--正文start-->` 专门正文提取逻辑。
  3. `--articles-json` 模式增加规则清洗兜底，AI 未覆盖的文章用 `summarize()` 补齐。
- 结果：2026-06-26 海报已重新生成并推送到飞书，16/16 条均有摘要（AI 13 条 + 规则兜底 3 条）。
- 代码已提交本地（commit 24a1c4d），GitHub 推送因网络超时暂时失败，需稍后重试。

## 摘要垃圾内容二次修复
- 用户反馈国内7/8摘要仍是垃圾（标题重复+版权声明+作者时间戳）。
- 根因：`_enrich_article_content()` 对视频页/图集页/自媒体页提取到垃圾内容后未识别；`summarize()` 直接截断当作摘要；`_score_article()` 未对无效摘要降权，导致垃圾文章仍被选中。
- 修复：
  1. 新增 `_is_garbage_content()` 识别版权声明、时间戳列表、标题重复、中文比例过低等垃圾模式。
  2. `_enrich_article_content()` 返回前检查垃圾内容，fetch 失败且无 RSS 摘要时返回空（不再用标题凑数）。
  3. `summarize()` 开头过滤垃圾内容，直接返回空。
  4. `_score_article()` 对无效摘要降权 -50。
  5. 新增 `_has_valid_summary()` 统一判断摘要有效性。
  6. 选稿后新增最终兜底：空/垃圾摘要自动用 fallback_articles 替换。
  7. 跳过 `video.sina.com.cn` 和 `slide.news.sina.com.cn` 等无正文页面。
- 结果：2026-06-26 海报第三次重新生成，16/16 条摘要均检查合格（无空白、无标题重复、无版权信息）。已推送到飞书。
- 代码已提交本地（commit 6d29b16），GitHub 推送仍因网络问题失败（443 连接超时）。
